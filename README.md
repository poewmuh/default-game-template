# DEFAULT-GAME-TEMPLATE
Default game architecture.

Unity Version: 6.3

Packages: VContainer, MessagePipe, R3, UniTask, Addressables, DOTween, vFolder, vHierarchy, CustumToolbar, Cinemachine.
Start Settings: 3D PC (easy change for 2D or Mobile), URP.

Including:
 1. Scene managment (support multiple additional scenes with seamless loading)
 2. IAudioSystem for any AudioSystem
 3. IAssetLoder with AddressablesLoader script
 4. IGUISystem (Windows, Overlays) managemnet loading/unloading
 5. LoadingStage (Scene Loading Progress Not Implement Now)
 6. Extension Utils for variables
 7. Free commercial use fonts and textures.
