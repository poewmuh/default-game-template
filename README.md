# DEFAULT-GAME-TEMPLATE
Default Unity game architecture.

Unity Version: 6.3

Packages: VContainer, MessagePipe, R3, UniTask, Addressables, DOTween, vFolders, vHierarchy, CustomToolbar, Cinemachine.
Start Settings: 3D PC (easy change for 2D or Mobile), URP.

Including:
 1. Scene management (supports multiple additive scenes with seamless loading)
 2. IAudioSystem for any AudioSystem
 3. IAssetLoader with AddressablesLoader script
 4. IGUISystem (Windows, Overlays) loading/unloading management
 5. LoadingStage
 6. Extension Utils for variables
 7. Free commercial use fonts and textures.
